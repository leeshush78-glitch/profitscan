ProfitScan UK v1

To install on Android:
1. Extract the ZIP.
2. Upload the contents of the profitscan-uk folder to a free HTTPS static website host (such as GitHub Pages or Cloudflare Pages).
3. Open the HTTPS URL in Chrome on Android.
4. Chrome menu > Add to Home screen / Install app.
5. Allow camera permission when prompted.

Features: barcode camera detection (where browser supports it), manual barcode input, Open Food Facts product name lookup (coverage limited), eBay UK active/sold search links, editable fees and resale price, conservative BUY/MAYBE/AVOID estimate, local inventory, status tracking, CSV export.

Important: no automatic eBay sold-price API integration; the user must check sold listings and enter a resale price. Estimates are not guaranteed. Data is stored only in the current browser/device and can be lost if browser data is cleared. Export CSV regularly. Open Food Facts may not recognise non-food products. API calls require internet and may be limited. Camera requires HTTPS and supported Android browser. No account, paid API, or server required for this first version.
